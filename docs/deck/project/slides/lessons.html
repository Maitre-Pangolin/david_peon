What made it work

Taste stays human

Claude can find, cut and level. Only ears can judge funny, and the review page made listening fast.

Local first

The model, the downloads and the review tool all ran on the laptop. Only the 52 finished clips are published.

Measure, don’t guess

A loudness meter and a comparison with other packs beat “sounds about right”.

Rules up front

No cloning, official sources only, credit the BBC: agreed before the first download.

If you try something similar: start by asking for a plan, not for the result. Short feedback at each checkpoint (“search more first”, “is that too much work?”) was enough to steer.
