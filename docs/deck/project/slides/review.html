A small local page for the listening

  • Play, then keep, maybe or reject: keys 1, 2, 3
  • Moves on and plays the next clip
  • Move a clip to another event
  • Nudge start or end by 0.1 s: re-cut on the spot
  • Saves to a JSON file that Claude reads next
Claude wrote this page and a tiny Python server for it, then tested it in its built-in browser: played a clip, nudged it, kept it, checked the file on disk, and reset everything before handing it over. The audio never left the laptop. Green edge = keep, amber = maybe, faded red = reject.
