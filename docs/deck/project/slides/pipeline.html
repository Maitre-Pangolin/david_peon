The process

Eight steps, each one a small script

01

Source

yt-dlp pulls audio only from 10 official videos: 134 MB

02

Transcribe

Whisper runs on the laptop and timestamps every word

03

Search

A search script lists every line under 5 s, plus keyword hunts

04

Shortlist

Claude reads 549 lines and proposes 80 in a TSV file

05

Cut

ffmpeg trims each line with padding and short fades

06

Review

A local page: listen, keep or reject, fix the edges

07

Level

Compressor, gain and limiter so every clip sounds as loud

08

Pack

Manifest and checksums, installed with peon-ping’s own command

Each step is a script in the repo, so the whole thing can be re-run. The only step that needed a human was 06: listening. Everything else Claude wrote, ran and checked, asking me before each download or install.
